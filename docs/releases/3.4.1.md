# 3.4.1：依赖补丁升级与 Android 选图修复

发布日期：2026-11-03。

本版本更新 Compose 配套依赖、构建工具与示例应用，并修复 Android 新版系统选图器取消后一直等待的问题。**从 3.4.0 升级不需要改写公开组件函数或 Builder 参数，Maven 坐标和平台变体保持不变。**

## 依赖与示例更新

| 项目 | 3.4.0 | 3.4.1 |
|---|---|---|
| Compose Multiplatform | 1.12.1 | 1.12.2 |
| Gradle Wrapper | 9.8.1 | 9.8.2 |
| JetBrains Navigation3（示例） | 1.1.2 | 1.2.0 |
| kotlinx-serialization-json（示例） | 1.11.0 | 1.12.0 |

| Android 示例 targetSdk | 34 | 36 |
| 依赖检查插件 | com.github.ben-manes.versions 0.54.0 | io.github.ben-manes.versions 0.67.0 |

Kotlin 2.4.21、AGP 9.1.1、compileSdk 37、minSdk 26、JVM toolchain 11、Lifecycle 2.11.0 及 Material3 1.12.0-alpha03 保持不变。示例专用依赖和 targetSdk 变化不等同于库消费者必须全部跟随。

Compose 1.12.2 修复 iOS 输入框因 Dialog 显示而失焦时崩溃、iOS Safari 27 输入焦点及非矩形阴影动画闪烁。Gradle 9.8.2 修复虚拟平台版本对齐误报警，沿用官方发行包与固定 SHA-256；此前安全补丁在 3.4.0 使用的 9.8.1 中已包含。

## 从 3.4.0 升级

1. 保留 README 中的 Google、Maven Central 与 GitHub Maven 仓库配置，更新依赖：

   ```kotlin
   implementation("com.github.D10NGYANG:DLJetpackComposeUtil:3.4.1")
   ```

2. 消费方若显式固定 Compose 版本，请同步评估 1.12.2，检查最终解析图。**Material3 使用独立版本号，不能机械替换为 1.12.2；AndroidX BOM 不管理 JetBrains KMP 坐标。**
3. Button、Field、Dialog、Sheet、Builder 与 `ImagePreview(path)` 等调用保持原写法。本次没有库公开 API 迁移。
4. 复用 Android Demo 选图代码的项目，应使用本版官方 `rememberLauncherForActivityResult(PickVisualMedia)` 实现。旧 DLAppUtil 2.7.1 的现代 Photo Picker 分支忽略取消时的 null URI，等待中的 Flow 不会完成；仅更新本库不会修复其他项目对 `PhotoManager.pick()` 的直接调用。
5. 独立升级 serialization 1.12 或 DLCommonUtil 1.x 时，注意反序列化异常包装和非法范围检查变化。本库不要求消费方为了使用 UI 组件额外加入这些示例依赖。

从 3.3.x 或更早版本升级时，先完成 [3.4.0 的 AGP/KMP 迁移](3.4.0.md)，包括 Android KMP library 插件、应用模块拆分和 compileSdk 37 要求。

## 修复与工程维护

- Android Demo 选取 JPEG 后以独立缓存文件交给既有图片预览组件；取消可正常返回并再次打开，读取失败显示提示，关闭预览、离开页面或协程取消时清理临时文件。
- 仪器测试验证实际“选择图片”按钮、Activity 重建后的预览、真实系统选择器连续取消、无效 URI 与缓存清理，保留 Activity 引用清理和强制 Sheet 返回拦截验证。
- Android Lint 仅对未使用的 DLAppUtil `NotificationController` 精确排除通知权限误报，未关闭本项目通知权限检查，也未增加无用途权限。
- 更新 checkout、setup-java、upload-pages-artifact 和 deploy-pages；CI 改用与 Daemon criteria 一致的 Corretto 21。

## 验证结果

- JVM、Android Host、iOS Simulator 单元测试各 5/5；两个 Android Demo、JVM/JS/Wasm/iOS 编译、完整 Xcode 模拟器构建、Dokka 与发布元数据检查通过。
- 华为 Android 12 和 Android 16 arm64 模拟器各 5/5 仪器测试；两平台各 22 项输入、键盘、Sheet 和 Dialog 操作断言通过。
- Web 开发包和生产包均覆盖 23 页与关键交互，无未捕获异常；30 组同尺寸截图中 28 组完全一致，其余仅加载动画微小差异，未发现布局回退。
- iOS 27 / iPhone 18 Pro 完成输入文本、Sheet 选择确认、输入弹窗填写确认的 XCTest 验收。
- Android Lint 通过，非阻塞资源/图标与工具弃用警告保留。

详情见 [升级与验收报告](../research/dependency-upgrade-2026-11-03.md)。

## 已知边界

- Material3 仍为 alpha；Gradle 9.8.2 高于 Kotlin 2.4.21 官方完整测试上限 9.7.0，本项目有实测证据，但不宣称官方矩阵覆盖。
- Web 保留既有 Wasm memory 弃用与 WebGL 提示；本轮未做全量供应链漏洞扫描或桌面原生 UI 验收。
- 示例 targetSdk 36 已验证 Android 12/16；未穷尽全部设备、原生预测性返回动画、字体缩放和横竖屏组合。
